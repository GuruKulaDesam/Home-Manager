# Consolidation map

Thirteen repositories were audited and reduced to three unique application lineages. Branding-only variants are represented once.

| Unified area | Source repositories |
| --- | --- |
| Home | Home-Manager, Divine-Nest, DivineNest, ShivohM, kovaipudur1c |
| Community | Kovaipudur-Edition, Kovaipudur, kovaipudur1a, kovaipudur1b |
| Study | ProdyJEE |
| No product source | KMS, NammaOorunga, Zysham |

The unified schema shares tasks, events, issues, contacts and point transactions using context/scope fields. Domain-specific records such as syllabus topics, news, discussions, polls, inventory and expenses retain their own collections.
